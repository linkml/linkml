# Security policy

## Supported versions

Security fixes are made against the latest release of `linkml` and `linkml-runtime`.
Please check that an issue reproduces on the latest release before reporting it.

## Reporting a vulnerability

Please do not open a public GitHub issue, discussion or pull request for a security
vulnerability.

Report it privately through GitHub instead: go to the
[Security tab](https://github.com/linkml/linkml/security) and click
"Report a vulnerability", or open a
[new advisory](https://github.com/linkml/linkml/security/advisories/new) directly.
Only you and the maintainers can see the report.

Please include the affected package and version, a description of the problem, and
steps or a minimal schema to reproduce it. We will acknowledge the report, keep you
updated while we work on a fix, and credit you in the advisory unless you prefer
otherwise.
